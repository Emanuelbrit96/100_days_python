# Dia 7 — Jogo de adivinhação

## Objetivo

Desenvolver um jogo no qual o computador sorteia um número entre `1` e `100`, e o jogador possui até sete tentativas para descobri-lo.

O desafio foi utilizado para praticar números aleatórios, estruturas de repetição, validações, contadores e controle do encerramento de um laço.

## Regras

O programa deverá:

1. solicitar o nome do jogador;
2. sortear um número inteiro entre `1` e `100`;
3. permitir no máximo sete tentativas;
4. solicitar um palpite em cada tentativa;
5. informar se o número secreto é maior ou menor;
6. encerrar o jogo quando o jogador acertar;
7. mostrar o número secreto quando as tentativas terminarem.

## Sorteio do número

Para gerar o número secreto, deverá ser utilizado o módulo `random`:

```python
import random
```

O número poderá ser sorteado com:

```python
random.randint(1, 100)
```

Os dois limites são incluídos. Portanto, o resultado poderá ser qualquer número inteiro de `1` até `100`.

## Validação do palpite

O palpite deverá estar entre `1` e `100`.

Se o jogador informar um valor fora desse intervalo, o programa deverá:

- mostrar uma mensagem de erro;
- solicitar outro palpite;
- não consumir uma tentativa.

Exemplo:

```text
Digite seu palpite: 150
Palpite inválido! Digite um número entre 1 e 100.
```

## Dicas

Quando o palpite for menor que o número secreto:

```text
O número secreto é maior.
```

Quando o palpite for maior que o número secreto:

```text
O número secreto é menor.
```

## Resultado em caso de vitória

```text
Parabéns, Emanuel!
Você acertou o número 43 na 4ª tentativa.
```

Ao acertar, o jogador não deverá receber novas tentativas nem visualizar a mensagem de derrota.

## Resultado em caso de derrota

Se as sete tentativas forem utilizadas sem acerto:

```text
Suas tentativas acabaram!
O número secreto era 43.
```

## Estrutura `while...else`

O programa utiliza o `else` associado ao `while`.

O bloco `else` será executado quando o laço terminar normalmente, ou seja, quando todas as tentativas forem utilizadas.

Quando o jogador acerta, o comando `break` encerra o laço e impede a execução do `else`.

Estrutura utilizada:

```python
while condição:
    if acertou:
        break
else:
    # executado somente quando não houve break
```

## Principais aprendizados

Neste desafio foi possível aprender que:

- `random.randint()` gera números inteiros aleatórios;
- o `continue` reinicia a repetição atual;
- um palpite inválido pode ser rejeitado sem aumentar o contador;
- o `break` encerra imediatamente o laço;
- o `else` do `while` não é executado quando ocorre um `break`;
- o contador deve avançar apenas depois de um palpite válido e incorreto;
- as mensagens “maior” e “menor” precisam considerar o número secreto como referência.
