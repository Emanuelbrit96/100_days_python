# Dia 1 — Analisador de sessão de estudos

## Objetivo

Criar um programa que receba informações sobre uma sessão de estudos, calcule o percentual de acertos e apresente um resumo.

## Dados solicitados

- Nome do estudante
- Assunto estudado
- Tempo estudado em minutos
- Quantidade de questões respondidas
- Quantidade de acertos

## Cálculo

Percentual de acertos = acertos / questões respondidas × 100

## Assuntos para estudar

- `print()`
- `input()`
- Variáveis
- Tipos `str`, `int` e `float`
- Conversão de tipos
- Operadores matemáticos
- F-strings

## Regras

- Receber os dados usando `input()`
- Utilizar nomes de variáveis claros
- Converter os dados numéricos
- Calcular o percentual no programa
- Exibir um resumo organizado
