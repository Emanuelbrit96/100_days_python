# Dia 8 — Analisador de texto

## Objetivo

Desenvolver um programa que receba uma frase e apresente informações sobre os caracteres e as palavras presentes no texto.

O desafio foi utilizado para aprofundar a manipulação de strings, a classificação de caracteres e o uso de contadores.

## Entrada

O programa deverá solicitar uma frase:

```text
Digite uma frase:
```

A entrada não poderá:

- estar vazia;
- conter somente espaços.

Caso isso aconteça, o programa deverá apresentar uma mensagem de erro e solicitar outra frase.

## Informações analisadas

O programa deverá calcular:

1. quantidade total de caracteres;
2. quantidade de caracteres sem contar os espaços;
3. quantidade de palavras;
4. quantidade de vogais;
5. quantidade de consoantes;
6. quantidade de algarismos;
7. quantidade de espaços;
8. quantidade de caracteres especiais.

## Validação da entrada

O método `.strip()` poderá ser utilizado para remover os espaços existentes no início e no final da frase:

```python
frase.strip()
```

Uma string vazia é considerada falsa pelo Python. Por isso, a expressão abaixo permite verificar se nenhum texto válido foi informado:

```python
not frase
```

O programa deverá repetir a solicitação enquanto a frase estiver vazia.

## Separação das palavras

O método `.split()` permite separar a frase em palavras:

```python
palavras = frase.split()
```

Quando utilizado sem argumento, ele ignora espaços repetidos.

Exemplo:

```text
Python   é   interessante
```

Será separado em três palavras.

## Classificação dos caracteres

Cada caractere deverá pertencer a somente uma das categorias abaixo.

### Espaços

```python
caractere.isspace()
```

### Vogais

Deverão ser consideradas as vogais comuns e acentuadas:

```text
a e i o u á à â ã é ê í ó ô õ ú
```

Antes da comparação, o caractere poderá ser transformado em minúsculo:

```python
caractere.lower()
```

### Consoantes

Se o caractere for uma letra, mas não estiver entre as vogais, deverá ser contado como consoante:

```python
caractere.isalpha()
```

### Algarismos

```python
caractere.isdigit()
```

A contagem será feita caractere por caractere. Portanto, o valor `2026` possui quatro algarismos.

### Caracteres especiais

Qualquer caractere que não seja espaço, vogal, consoante ou algarismo será classificado como especial.

Exemplos:

```text
! ? . , " @ # $ % & ( )
```

## Ordem da classificação

A ordem das verificações é importante:

1. espaço;
2. vogal;
3. consoante;
4. algarismo;
5. caractere especial.

Uma estrutura com `if`, `elif` e `else` garante que cada caractere seja contado em somente uma categoria.

## Exemplo de execução

```text
Digite uma frase: "A frase não pode estar vazia.

===== ANÁLISE DO TEXTO =====
Texto: "A frase não pode estar vazia.
Total de caracteres: 30
Caracteres sem espaços: 25
Quantidade de palavras: 6
Vogais: 12
Consoantes: 11
Números: 0
Espaços: 5
Caracteres especiais: 2
```

Nesse exemplo, os caracteres especiais são a aspa e o ponto final.

## Principais aprendizados

Neste desafio foi possível aprender que:

- strings podem ser percorridas caractere por caractere;
- `split()` sem argumento lida corretamente com espaços repetidos;
- cada caractere deve ser classificado diretamente;
- obter consoantes por subtração pode provocar resultados incorretos;
- o `else` pode representar qualquer caractere que não pertence às categorias anteriores;
- métodos booleanos já retornam `True` ou `False`;
- um número com vários algarismos é formado por vários caracteres.

## Desafio extra

Um palíndromo pode ser lido da mesma forma nos dois sentidos:

```text

radar
osso
```

Uma string pode ser invertida por meio de fatiamento:

```python
palavra[::-1]
```

Para evitar diferenças entre letras maiúsculas e minúsculas, a palavra deverá ser normalizada antes da comparação.
