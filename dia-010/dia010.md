# Dia 10 — Quiz de Python

## Objetivo

Desenvolver um quiz de conhecimentos básicos sobre Python, registrando as respostas do jogador, calculando sua pontuação e apresentando uma revisão completa ao final.

O Dia 10 funciona como um projeto de revisão dos conteúdos praticados nos primeiros desafios.

## Estrutura dos dados

O programa utiliza listas relacionadas pelos índices:

```python
perguntas = []
alternativas = []
respostas_corretas = []
respostas_jogador = []
```

Cada posição representa uma mesma questão.

Exemplo:

```python
perguntas[0]
alternativas[0]
respostas_corretas[0]
respostas_jogador[0]
```

Todos esses elementos pertencem à primeira questão.

## Menu inicial

Antes de começar, o programa deverá apresentar:

```text
1 — Iniciar o quiz
2 — Sair
```

Somente as opções `1` e `2` deverão ser aceitas.

Se o jogador escolher `1`, o quiz será iniciado. Caso escolha `2`, o programa será encerrado.

## Identificação do jogador

O programa deverá solicitar o nome do jogador.

O nome:

- não poderá estar vazio;
- não poderá conter somente espaços;
- deverá ser solicitado novamente quando for inválido.

## Apresentação das questões

Cada questão deverá mostrar:

- número atual;
- quantidade total de perguntas;
- enunciado;
- alternativas;
- campo para resposta.

Exemplo:

```text
===== QUESTÃO 1 DE 5 =====
Qual função é usada para receber dados do usuário?

A) print() | B) input() | C) len()

Resposta:
```

## Validação das respostas

Somente estas alternativas serão aceitas:

```text
A
B
C
```

O programa deverá aceitar letras maiúsculas e minúsculas por meio de:

```python
.strip().upper()
```

A validação deverá utilizar uma coleção de opções:

```python
resposta in ("A", "B", "C")
```

Uma resposta inválida:

- não deverá ser adicionada à lista;
- não deverá avançar para a próxima questão;
- deverá ser solicitada novamente.

## Correção

Depois de receber uma alternativa válida, o programa deverá:

1. comparar a resposta com o gabarito;
2. aumentar o contador de acertos quando necessário;
3. informar se houve acerto ou erro;
4. adicionar a resposta à lista do jogador.

Exemplo de acerto:

```text
Resposta correta!
```

Exemplo de erro:

```text
Resposta incorreta!
A alternativa correta era B.
```

## Cálculo do resultado

O percentual de aproveitamento será calculado por:

```text
percentual = acertos ÷ quantidade de perguntas × 100
```

A quantidade de erros será:

```text
erros = quantidade de perguntas - acertos
```

## Classificação

| Aproveitamento | Classificação |
|---:|---|
| De 0% até 39,99% | Precisa revisar |
| De 40% até 69,99% | Razoável |
| De 70% até 89,99% | Muito bom |
| De 90% até 100% | Excelente |

## Resultado esperado

```text
===== RESULTADO DO QUIZ =====
Jogador: Emanuel
Quantidade de perguntas: 5
Acertos: 4
Erros: 1
Aproveitamento: 80.00%
Classificação: Muito bom
```

## Revisão das respostas

Ao final, o programa deverá percorrer novamente as listas e apresentar:

```text
===== REVISÃO =====

Questão 1
Sua resposta: B
Resposta correta: B
Situação: Acertou

Questão 2
Sua resposta: A
Resposta correta: B
Situação: Errou
```

A revisão será construída relacionando:

```python
respostas_jogador[i]
respostas_corretas[i]
```

## Conceitos praticados

- criação de listas;
- listas relacionadas por índices;
- método `.append()`;
- função `len()`;
- métodos `.strip()`, `.upper()` e `.title()`;
- estrutura de repetição `for`;
- estrutura de repetição `while`;
- estruturas `if`, `elif` e `else`;
- operador `in`;
- validação de entrada;
- contadores;
- cálculo de porcentagem;
- f-strings;
- organização de um programa maior.

## Principais aprendizados

Neste desafio foi possível aprender que:

- diferentes listas podem representar partes relacionadas de um registro;
- o mesmo índice permite acessar a pergunta, o gabarito e a resposta do jogador;
- respostas precisam ser normalizadas antes da comparação;
- usar `in ("A", "B", "C")` verifica elementos exatos;
- usar `in "ABC"` também pode aceitar trechos como `"AB"` e até uma string vazia;
- uma resposta somente deve ser armazenada depois da validação;
- a quantidade de erros pode ser calculada a partir do total e dos acertos;
- dados armazenados podem ser percorridos novamente para gerar um relatório.

Esse problema será tratado futuramente com:

```python

except
```

## Desafio extra

```text
Deseja jogar novamente? (s/n)
```

Quando a resposta for `s`, o programa deverá:

- zerar o contador de acertos;
- limpar a lista de respostas do jogador;
- executar novamente todas as perguntas.

Quando a resposta for `n`, o programa deverá ser encerrado.
